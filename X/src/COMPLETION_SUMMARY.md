## 📊 系統數據

### 玩家屬性擴展
```javascript
// 新增屬性
疲勞度: 0/100
飽食度: 100/100
背包容量: 20/20
生活技能 × 4: 等級 1-5
技能經驗: 0/100 (可升級)
根據地位置: baseId 或 null
是否在根據地: boolean
```

### 遊戲常量
```
行動值恢復: 每小時 +1
飽食度消耗: 野外 -10/小時, 根據地 -5/小時
疲勞度消耗: 取決於活動
飢餓懲罰: 連續 1 天 -10 HP, 3 天死亡
死亡掉落: 50% 物品, 全屬性 -20%
時間加速: 10 秒 = 1 小時
```

## 🎮 遊戲流程

### 推薦的遊戲流程

**Day 1**
1. 探索周邊場景（獲得基礎物品）
2. 選擇位置建造根據地
3. 建造床和陶罐
4. 進食和休息

**Day 2-3**
1. 定期外出探索採集
2. 每日返回根據地進食睡眠
3. 提升技能等級
4. 擴建根據地設施

**Day 4+**
1. 建立完整的生存循環
2. 優化資源管理
3. 挑戰強大敵人
4. 探索更遠的區域

## 🔍 技術細節

### 新增函數清單
- `checkHungerSystem()` - 飢餓檢查
- `playerDeath()` - 死亡處理
- `buildBase()` - 建造根據地
- `sleepAtBase()` - 在根據地睡眠
- `eatAtBase()` - 在根據地進食
- `returnToBase()` - 返回根據地
- `goExplore()` - 外出探索
- `addSkillExp()` - 增加技能經驗
- `addItemToBackpack()` - 添加物品到背包
- `moveItemToBase()` - 移動物品到根據地
- `takeItemFromBase()` - 從根據地取出物品
- `checkNightDanger()` - 檢查夜間危險
- `constructStructure()` - 建造設施
- `generateBaseResources()` - 生成根據地資源
- `updateBaseUI()` - 更新根據地 UI
- `startTimeSystem()` - 啟動時間系統

### 新增數據結構
- `baseTypes` - 根據地類型定義
- `baseStructures` - 根據地設施定義
- `gameState.bases` - 根據地存儲
- `gameState.gameDay` - 遊戲日期
