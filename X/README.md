====================================

## 🎮 遊戲概述

**孫氏集團職場冒險遊戲** 是一個整合式遊戲系統，結合了：
- 角色卡系統（4位主要角色的完整設定）
- 中世紀探險遊戲機制（改為荒島背景）
- 完整的圖片資源庫（SVG格式，便於替換和編輯）

---

## 📂 檔案結構

### 主要文件（X/src/）

#### 🎮 遊戲入口
- **game.html** - 主菜單和遊戲啟動器
  - 提供三個主要選項：角色介紹、開始遊戲、圖庫資源
  - 使用iframe集成所有子頁面
  - ESC鍵快速返回菜單

#### 👥 角色系統
- **characters.js** - 角色數據系統
  - 4位主要角色的完整設定
  - 包含：基本信息、外觀描述、個性特徵、人際關係、背景故事、心理分析、日常作息
  - 可擴展的角色數據結構

- **character_cards.html** - 角色卡片展示
  - 快速瀏覽所有角色的卡片視圖
  - 可按角色篩選查看
  - 詳細資料檢視（外觀、個性、關係、背景）

- **character_details.html** - 角色全身描寫
  - 完整的角色視覺化展示
  - 三大標籤頁：全身外觀、個性心理、日常生活
  - 深入的角色分析和描寫

#### 🎨 資源管理
- **game-resources.js** - 圖片資源數據庫
  - 包含所有角色SVG圖片定義
  - 包含所有荒島場景SVG背景
  - 提供資源管理函數
  - 結構清晰，便於日後擴展和替換

- **gallery.html** - 圖庫資源展示
  - 角色圖片展示
  - 荒島場景展示
  - 資源統計信息
  - JSON和SVG匯出功能

#### 🎮 遊戲系統
- **medieval_rpg.html** - 遊戲主頁面
  - 原始的中世紀探險遊戲框架
  - 包含戰鬥系統、探索系統、任務系統

- **medieval_rpg.js** - 遊戲邏輯系統
  - 1709行完整代碼
  - 包含：
    - 遊戲狀態管理
    - 場景系統
    - 敵人系統
    - 戰鬥系統
    - 時間系統
    - 飢餓和疲勞系統
    - 根據地系統
    - 生活技能系統

## 🎨 圖片資源使用

### SVG 資源優勢
✅ 無損縮放，質量不變
✅ 文件體積小
✅ 易於編輯和動畫化
✅ 可直接在HTML中修改顏色和樣式

### 替換資源步驟

#### 1. 替換角色圖片
在 `game-resources.js` 中修改對應的SVG：
```javascript
sunLiliSvg: `
    <svg viewBox="0 0 200 400">
        <!-- 修改SVG內容 -->
    </svg>
`
```

#### 2. 替換場景背景
在 `game-resources.js` 中修改對應的背景SVG：
```javascript
backgrounds: {
    islandEntranceBg: `
        <svg viewBox="0 0 1920 1080">
            <!-- 修改SVG內容 -->
        </svg>
    `
}
```

#### 3. 添加新角色
在 `characters.js` 中添加新角色對象，在 `game-resources.js` 中添加對應的SVG

### 匯出資源
在圖庫頁面可以：
- 📥 下載角色JSON
- 📥 下載場景JSON
- 📥 下載所有SVG

## 📊 遊戲系統

### 核心系統
1. **場景系統** - 12個不同的荒島場景
2. **戰鬥系統** - 回合制戰鬥，包含元素克制
3. **探索系統** - 在各場景尋找物品和敵人
4. **根據地系統** - 建造和管理自己的營地
5. **時間系統** - 基於GMT+8的實時時間
6. **生活技能系統** - 探索、鑑定、建造、研發

### 角色屬性
- HP（血量）
- Attack（攻擊）
- Defense（防禦）
- Speed（速度）
- Crit（爆擊率）
- Hunger（飽食度）
- Fatigue（疲勞度）
- Action Points（行動值）

### 元素系統
火 → 水 → 地 → 風 → 木 → 火（相剋循環）

## 🔧 開發者指南

### 添加新場景
1. 在 `game-resources.js` 中的 `scenes` 對象添加新場景
2. 在 `backgrounds` 對象中添加對應的SVG
3. 在 `medieval_rpg.js` 中的 `scenes` 對象添加場景定義

### 修改遊戲規則
編輯 `medieval_rpg.js` 中的相應函數：
- `startBattle()` - 修改戰鬥規則
- `exploreScene()` - 修改探索規則
- `checkHungerSystem()` - 修改飢餓系統
- `generateBaseResources()` - 修改資源生成

### 自定義角色
編輯 `characters.js` 和 `game-resources.js` 中的角色數據和SVG
